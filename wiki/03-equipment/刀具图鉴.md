# 刀具图鉴

> 所属模块：03 装备系统 | 依赖：装备系统总览、转刀机制、拼刀机制 | 被依赖：伤害公式、平衡性分析、关卡设计

---

## 1. 设计目标

19 把差异化刀具，覆盖白→橙全品质、5 大 Build 方向。每把刀提供**可感知的玩法差异**：刀长/刀宽/转速/伤害/特效的组合变化，直接影响转刀手感与拼刀动量。

> 注：原称"20 把"为笔误，实际 19 把（白 3 / 绿 4 / 蓝 4 / 紫 5 / 橙 3，含剧情刀破镜重圆），与[属性总表](../06-balance/属性总表.md) §7 一致（M4 数据录入正式裁决）。

## 2. 刀具属性字段说明

| 字段 | 说明 |
| --- | --- |
| 名称 | 刀具名 |
| 品质 | 白/绿/蓝/紫/橙 |
| 基础伤害 | 每次命中结算的伤害基值（关1基准） |
| 刀长 L | 刀尖到旋转中心距离（px） |
| 刀宽 W | 刀体碰撞厚度（px） |
| 转速修正 | 对角速度的百分比修正 |
| 特殊效果 | 机制型词条 |
| 获取关卡 | 首次可获取的关卡 |
| 描述 | 设定文案 |

> 刀体动量 M = L × W × ω × Q，品质系数 Q：白1.0/绿1.15/蓝1.3/紫1.5/橙1.8（见 [拼刀机制](../02-combat/拼刀机制.md)）

## 4. Build 方向对照表

| Build 方向 | 推荐刀具 | 搭配词条 |
| --- | --- | --- |
| **转速流** | 柳叶刀、圆月弯刀、千叶流光刀 | 转速+、多刀、连击 |
| **范围流** | 玄铁重刀、虎啸狂刀、屠龙刀 | 半径+、刀长+、击退 |
| **暴击流** | 龙鳞刀、藏锋·无名 | 暴击率、暴击伤害 |
| **特效流** | 虎牙短刀、赤焰刀、寒月刀 | 流血、灼烧、减速 |
| **拼刀流** | 鬼头刀、圆月弯刀、屠龙刀、破镜重圆 | 拼刀胜率、拼刀伤害、破刀 |
| **续航流** | 牛角刀、破镜重圆 | 吸血、击杀回复 |

## 5. 刀具强度梯度（关6满强化基准 DPS 对比）

| 梯度 | 刀具 | 说明 |
| --- | --- | --- |
| T0 | 屠龙刀、藏锋·无名 | 数值与机制全面领先，Build 终点 |
| T1 | 千叶流光刀、虎啸狂刀、龙鳞刀 | 单一方向极致 |
| T2 | 玄铁重刀、圆月弯刀、赤焰刀、寒月刀 | 泛用中坚 |
| T3 | 雁翎刀、鬼头刀、精钢刀等 | 过渡或特定玩法 |

## 6. 刀具图鉴收集进度

图鉴系统：每解锁一把刀具记录进图鉴，全收集奖励永久增益（解锁挑战模式）。图鉴展示刀具设定文案与故事，是收集动机的一部分。
