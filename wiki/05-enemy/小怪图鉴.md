# 小怪图鉴

> 所属模块：05 敌人与Boss系统 | 依赖：碰撞引擎设计、拼刀机制、升级曲线与经验 | 被依赖：伤害公式、平衡性分析、关卡设计

---

## 1. 设计目标

15 种差异化小怪，分 4 大类。持刀型小怪参与拼刀机制，是战斗深度的来源。每种小怪有明确的**战术定位**，迫使玩家调整走位与拼刀策略。

## 2. 小怪类型分类

| 类型 | 特征 | 拼刀 | 战术定位 |
| --- | --- | --- | --- |
| **无刀型** | 无刀体，近战撞击/远程投射 | 否 | 数量多、脆皮，经验与掉落来源 |
| **持刀型** | 携带旋转刀体 | **是** | 博弈型对手，需拼刀或绕侧 |
| **远程型** | 远距离投射 | 否 | 干扰走位，需优先击杀 |
| **精英型** | 强化属性+特殊机制 | 部分持刀 | 小Boss，高奖励 |

## 3. 属性字段说明

| 字段 | 说明 |
| --- | --- |
| HP | 生命值（关1基准，随关卡缩放 ×(1+0.15×(关-1))） |
| 移速 | 移动速度（px/s） |
| 伤害 | 接触/攻击伤害（每次） |
| 防御 | 防御值（普通小怪 0-10，精英 25-35），用于减伤率 `防御/(防御+100)`（见 [伤害公式](../06-balance/伤害公式.md) §3.2） |
| 攻击方式 | 行为模式 |
| 是否持刀 | 是否有刀体参与拼刀 |
| 刀具参数 | 持刀型：刀长/刀宽/角速度/品质Q |
| 掉落 | 金币/碎片/装备概率 |
| 出现关卡 | 首次出现关卡 |
| 基础EXP | 见 [升级曲线与经验](../04-upgrade/升级曲线与经验.md) |

## 5. 小怪 AI 行为模式

| 行为 | 说明 | 适用 |
| --- | --- | --- |
| **追踪** | 直奔玩家，接触造成伤害 | 喽啰、恶犬、大部分近战 |
| **冲刺** | 蓄力后高速直线冲撞 | 恶犬、铁甲护卫、剑奴 |
| **保持距离** | 维持射程，远离玩家 | 远程型 |
| **包围** | 多只从不同方向接近 | 群体行为（喽啰、刀手） |
| **撤退** | HP 低时拉开距离回血 | 精英型部分 |
| **自爆** | 接近后引爆 | 邪教徒 |
| **持刀旋转** | 移动同时刀体旋转，被动攻击 | 持刀型 |

### 5.1 行为参数表（M5 实现确认值）

> 文档原只给行为标签；以下参数为开发 M5 里程碑时确认的实现值（代码 `src/enemy/AIParams.ts`）。

**冲刺（三档参数）**：

| 怪 | 冷却 | 蓄力 | 冲速 | 持续 |
| --- | --- | --- | --- | --- |
| 恶犬 | 4s | 0.4s | 300px/s | 0.5s |
| 铁甲护卫 | 6s | 0.8s | 260px/s | 0.7s |
| 剑奴 | 5s | 0.5s | 320px/s | 0.5s |

> 冷却口径（#003 修正）：冷却自**冲刺结束**起算，蓄力与冲刺本身不占用冷却，冲刺结束后休息完整冷却时长才可再次蓄力；蓄力被玩家击打断时，冷却仍自当次蓄力触发起算。原实现存在"冲刺结束帧过冲正值被误判为新蓄力"导致的零前摇连冲 bug，已修复（详见 [测试小修记录 #003](../11-report/测试小修记录.md)）。

**特殊行为**：

| 行为 | 参数 |
| --- | --- |
| 邪教徒自爆 | 触发距离 60px / 引信 1s（发光预警）/ 伤害 ×3 / 爆炸半径 90px / 自爆后死亡 |
| 打手 AOE | 前摇 0.6s / 打击半径 80px |
| 远程通用 | 射程 500px / 弹速 350px/s / 攻击间隔 2.5-3.5s（错峰）/ 走位区间 [300,500]px |

**通用规则**：所有前摇带红光视觉预警；蓄力中被击打断（奖励读招）；冲刺执行中不可打断（击退免疫）；玩家受击无敌帧 0.5s 限频。

**飞刀客弹道拼刀**：旋转飞刀为移动线段碰撞体——玩家刀体扫掠命中直接击碎；飞刀线段与玩家刀体相交触发**瞬时拼刀**（胜率固定 70%，胜=击碎无伤，败=受飞刀伤害，沿用 Boss 血刀斩先例）。瞬时拼刀胜 +25 拼刀经验。

## 6. 小怪刷新规则与波次设计

### 6.1 刷新规则

- 每个房间/区域有**刷怪点**与**刷怪池**（由关卡配置）
- 玩家进入区域触发刷怪，清空当前波次后开启下一波/通关
- 同时在场敌人上限：关1-2 为 12 只，关3-4 为 18 只，关5-6 为 24 只（性能与难度平衡）

### 6.2 波次结构

每个房间通常 2-3 波：
- 第 1 波：无刀型为主（消耗玩家走位）
- 第 2 波：混入持刀型/远程型（增加博弈）
- 第 3 波（精英房）：精英型 + 杂兵（高潮）

### 6.3 关卡刷怪池配置

| 关卡 | 主刷怪池 | 精英 |
| --- | --- | --- |
| 1 | 喽啰、恶犬、寨刀手 | - |
| 2 | 喽啰、打手、双刀匪、弓箭手、山贼头目 | 山贼头目 |
| 3 | 打手、邪教徒、血刀僧、毒镖手 | 血刀僧 |
| 4 | 鬼面刀客、飞刀客、铁甲护卫 | 铁甲护卫 |
| 5 | 神刀弟子、飞刀客、剑奴 | 剑奴 |
| 6 | 全池随机（高强化） | 剑奴+山贼头目 |

## 7. 持刀型小怪拼刀动量参考

以关1玩家铁匠刀（L80/W6/ω200°≈3.49rad/Q1.0）为基准，动量 M = 80×6×3.49×1.0 ≈ 1675。

| 小怪 | 刀体动量(关1) | 与玩家基准比 | 拼刀胜率(玩家) |
| --- | --- | --- | --- |
| 寨刀手 | 70×6×3.14×1.0 ≈ 1319 | 0.79 | 56% |
| 双刀匪(单刀) | 60×5×3.84×1.0 ≈ 1152 | 0.69 | 59% |
| 山贼头目 | 85×7×2.97×1.15 ≈ 2038 | 1.22 | 45% |
| 血刀僧 | 80×6×3.49×1.15 ≈ 1926 | 1.15 | 46% |
| 鬼面刀客 | 90×8×3.32×1.3 ≈ 3108 | 1.86 | 35% |
| 神刀弟子 | 95×7×3.67×1.3 ≈ 3171 | 1.89 | 35% |
| 剑奴(单刀) | 75×6×4.01×1.3 ≈ 2346 | 1.40 | 42% |

> 随关卡提升，小怪 HP/伤害缩放但**刀体动量基本不变**（刀体参数固定），保证玩家通过刀法/刀具成长后拼刀胜率提升，体现成长。
