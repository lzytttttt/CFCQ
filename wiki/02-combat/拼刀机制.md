# 拼刀机制

> 所属模块：02 战斗与碰撞系统 | 依赖：转刀机制、碰撞引擎设计 | 被依赖：Boss设计、小怪图鉴、伤害公式、平衡性分析

---

## 1. 设计目标

**拼刀**是《藏锋出鞘》的战斗核心深度。当玩家刀体与敌方刀体（持刀小怪/Boss 的旋转刀体）相撞时，触发一次"以刃对刃"的判定与解算。目标：

- 让"携带刀具的敌人"成为区别于普通怪的**博弈型对手**
- 玩家可通过主动拼刀**瞬间瓦解强敌攻势**，但拼输需承担风险
- 形成"走位找角度 vs 迎刃拼刀"的双层决策空间

## 2. 拼刀触发条件

触发需同时满足：

1. **空间条件**：玩家刀体与敌方刀体发生线段相交（碰撞引擎粗筛+精筛命中）
2. **刃锋条件**：双方刀体均处于**有效斩杀段**（非刀柄段，即 0.35L 之外）
3. **冷却条件**：双方拼刀冷却均已结束（拼刀后 CD 1.2 秒，防连续触发抖刀）
4. **姿态条件**：敌方处于可拼刀姿态（僵直/蓄力中不可拼刀）

> 注：远程武器（弓弩）与钝器敌人的"假刀体"不参与拼刀，这类敌人以常规命中处理（详见 [小怪图鉴](../05-enemy/小怪图鉴.md)）。

## 3. 核心参数：刀体动量

**刀体动量 M** 是拼刀胜负的核心综合参数：

```
M = L × W × ω × Q
```

| 符号 | 参数 | 说明 |
| --- | --- | --- |
| L | 刀长 | 刀体长度（px） |
| W | 刀宽 | 刀体宽度（px） |
| ω | 当前角速度 | 旋转角速度（rad/s） |
| Q | 品质系数 | 由刀具品质决定：白1.0 / 绿1.15 / 蓝1.3 / 紫1.5 / 橙1.8 |

**设计解读**：
- 刀长、刀宽即"刀具体积"，体积越大拼刀越有优势 → 鼓励走"巨刃流"
- 角速度越高动量越大 → 刀法等级间接强化拼刀
- 品质系数让高品质刀在拼刀中天然占优，但**操作与时机仍可翻盘**

## 4. 胜负判定公式

双方动量比较，结合**相对角速度方向**微调：

```
胜率(玩家) = clamp( M_player / (M_player + M_foe) , 0.1 , 0.9 )
```

| 动量比 M_p : M_f | 玩家胜率 | 结果倾向 |
| --- | --- | --- |
| 3 : 1 | 75% | 玩家显著优势 |
| 2 : 1 | 67% | 玩家优势 |
| 1 : 1 | 50% | 势均力敌 |
| 1 : 2 | 33% | 敌方优势 |
| 1 : 3 | 25% | 敌方显著优势 |

**额外修正**（±各不超过 0.05）：
- 玩家处于**相向**旋转（逆刃切换方向，与敌方刀旋转方向相对）：+0.05
- 玩家拼刀**时机窗口**内（敌方刀刚出刀 0.25 秒内）：+0.05
- 敌方处于**连击加成状态**（多刀叠加）：-0.05

> 结果按概率掷点确定（一次判定），并在 UI 上以"拼刀刻度/风险提示"可视化（黄色=均势、绿色=优势、红色=劣势）。

## 5. 解算结果类型

| 结果 | 玩家 | 敌方 | 说明 |
| --- | --- | --- | --- |
| **胜（击溃）** | 无损 | 刀体被弹开 45°，进入**僵直 1.5s**，失去刀体攻击 2s | 白嫖一次破势窗口，可安全输出 |
| **败（被弹开）** | 刀体弹开 45°，**僵直 0.8s**，失去刀体 1s | 无损 | 硬直惩罚，需走位规避敌方输出 |
| **平（硬碰硬）** | 双方弹开，各僵直 0.4s | 同左 | 势均力敌，各自拉开重新起手 |
| **破刀（大胜，概率触发）** | 无损 | 刀具"刃崩"：敌方攻击力-30% 持续 10s | 仅在玩家动量优势 ≥ 2 倍且有天赋加成时触发 |

## 6. 拼刀伤害计算

拼刀胜利本身**不造成伤害**，但提供**破势**状态；破刀除外（产生一次拼刀伤害）。拼刀后玩家在敌方僵直期间的普通命中享受**破势加成**：

```
破势命中伤害 = 普通伤害 × 1.5
```

若触发**破刀**，额外结算一次拼刀伤害：

```
拼刀伤害 = 玩家刀体动量 × 伤害系数 / 1000
         = M_player × 0.02   （基准，M=15000 时造成 300 伤害）
```

## 7. 拼刀奖励机制（高风险高回报）

| 奖励 | 条件 | 效果 |
| --- | --- | --- |
| 破势加成 | 拼刀胜 | 后续命中 +50% 伤害（敌僵直期间） |
| 破刀奖励 | 破刀触发 | 额外拼刀伤害 + 敌方 10s 攻击力-30% |
| 拼刀经验 | 每次拼刀 | +25 经验（约等于击杀 1.5 个同级小怪） |
| 拼刀金币 | 拼刀胜 | +10~30 金币 |
| 连破奖励 | 连续 3 次拼刀胜 | 触发"刀势如虹"：8 秒内刀法全属性 +20% |

**风险**：拼刀败 → 僵直 0.8s + 失去刀体 1s，期间完全无法攻击且暴露在敌人输出下。

## 8. 拼刀策略深度分析

```
          高风险
            ↑
  主动迎刃拼刀 │ 侧身躲刀再反击
  （赌动量胜率）│  （安全但慢）
            │
  --------+-------→ 低风险
  贴脸硬刚大体积 │ 拉开距离旋转收割
  （高动量优势）│  （小怪拼刀）
```

- **对持刀小怪**：小怪动量通常低于玩家 → 主动拼刀快速破势，高效清怪
- **对精英/Boss**：Boss 刀体动量大，主动拼刀胜率被压低 → 需要：攒刀法提升 ω、换大体积刀具、利用逆刃相向加成、抓 Boss 出刀窗口
- **走位流**：完全不拼刀，靠绕侧/拉开打安全输出，代价是 Boss 战时间拉长、错过破势奖励
