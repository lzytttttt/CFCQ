# 伤害公式

> 所属模块：06 数值平衡系统 | 依赖：转刀机制、拼刀机制、装备系统、升级系统、小怪图鉴、Boss设计 | 被依赖：属性总表、平衡性分析

---

## 1. 设计目标

定义一套**完整、可验证、可调参**的伤害计算体系，覆盖：普通命中、连击、暴击、拼刀、击退、减伤。所有数值参数集中可调，确保平衡性可控。

## 2. 伤害类型

| 类型 | 说明 | 适用 |
| --- | --- | --- |
| **物理伤害** | 常规刀体命中，受防御减免 | 绝大多数攻击 |
| **真实伤害** | 无视防御与减伤 | 拼刀破刀、特定技能 |
| **持续伤害** | 流血/灼烧/中毒，按时间结算 | 特效刀具、毒镖 |

## 3. 普通命中伤害公式

### 3.1 基础公式

```
最终伤害 = round(
    刀具基础伤害
    × (1 + 刀具等级伤害加成)
    × (1 + 装备强化锋刃加成)
    × (1 + 装备词条攻击加成 + 套装攻击加成)
    × 刀法系数
    × 连击倍率
    × 暴击倍率(若暴击)
    × (1 - 敌人减伤率)
)
```

### 3.2 各因子定义

| 因子 | 来源 | 公式/说明 |
| --- | --- | --- |
| 刀具基础伤害 | [刀具图鉴](../03-equipment/刀具图鉴.md) | 随关卡缩放：`基础 × (1+0.12×(关-1))` |
| 刀具等级伤害加成 | [刀具强化路线](../04-upgrade/刀具强化路线.md) | `0.035 × (刀具Lv-1)` |
| 装备强化锋刃加成 | 装备强化 | `0.06 × 锋刃层数` |
| 装备词条攻击加成 | 词条 | 攻击力+%词条之和 |
| 套装攻击加成 | 套装效果 | 套装提供的攻击% |
| 刀法系数 | [刀法升级树](../04-upgrade/刀法升级树.md) | `1 + 0.04 × (刀法Lv-1)` |
| 连击倍率 | [转刀机制](../02-combat/转刀机制.md) | 1.0/1.15/1.3/1.5/1.8（连击1-5） |
| 暴击倍率 | 词条/套装 | 默认 1.5，暴击伤害词条叠加 |
| 敌人减伤率 | 敌人防御 | `防御 / (防御 + 100)`，普通小怪防御 0-10 |

### 3.3 计算示例（关3玩家，蓝装雁翎刀，刀法Lv9，刀具Lv8）

| 因子 | 值 |
| --- | --- |
| 雁翎刀基础伤害 | 34 |
| 关卡缩放(关3) | ×1.24 → 42 |
| 刀具等级加成(Lv8) | 1+0.035×7 = 1.245 → 52 |
| 装备强化锋刃(3层) | 1+0.06×3 = 1.18 → 61 |
| 装备词条攻击(15%) | ×1.15 → 70 |
| 套装攻击(0%) | ×1.0 → 70 |
| 刀法系数(Lv9) | 1+0.04×8 = 1.32 → 93 |
| 连击倍率(连击3) | ×1.3 → 120 |
| 暴击(10%率,1.5倍) | 期望 ×1.05 → 126 |
| 敌人减伤(防御5) | ×(1-5/105)=×0.952 → 120 |

**结论**：关3单次命中期望约 120 伤害，3连击约 120+138+156=414。

## 4. 拼刀伤害公式

### 4.1 拼刀胜利（破势）

拼刀胜本身**不直接造伤害**，但赋予**破势状态**：敌僵直期间（1.5s）玩家命中 ×1.5。

### 4.2 破刀伤害（大胜触发）

```
拼刀伤害 = round( 玩家刀体动量 M_player × 0.02 )
```

示例：M=1675（关1基准）→ 拼刀伤害 34；M=4000（关5）→ 80。

### 4.3 连破Buff"刀势如虹"

连续3次拼刀胜触发，8秒内刀法全属性 +20%（含伤害、转速、半径）。

## 5. 击退力计算

```
击退距离 = 基础击退(20px) 
         × (1 + 刀具击退加成) 
         × (1 + 装备强化破势加成) 
         × (1 + 击退词条 + 套装击退) 
         × 连击击退衰减(连击数越多衰减越小, 1 - 0.1×min(连击,3))
```

击退方向：刀体线段在命中点的切线方向。

## 6. 持续伤害（流血/灼烧/中毒）

| 类型 | 结算 | 叠加 |
| --- | --- | --- |
| 流血 | 每0.5s 3伤害，持续5s（共30） | 刷新持续时间，不叠加层数 |
| 灼烧 | 每0.5s 4伤害，持续5s（共40） | 同上 |
| 中毒 | 每1s 5伤害+减速30%，持续3s（共15+减速） | 同上 |

> 持续伤害为**真实伤害**，无视防御。

## 7. 玩家受伤与减伤

### 7.1 玩家受伤公式

```
玩家受伤 = round( 敌人伤害 × (1 - 玩家减伤率) )
玩家减伤率 = 护甲防御 / (护甲防御 + 120)
```

### 7.2 玩家HP与护甲

| 关卡 | 玩家HP | 推荐护甲防御 | 减伤率 |
| --- | --- | --- | --- |
| 1 | 100 | 5 | 4% |
| 2 | 130 | 10 | 7.7% |
| 3 | 165 | 15 | 11.1% |
| 4 | 205 | 22 | 15.5% |
| 5 | 250 | 30 | 20% |
| 6 | 300 | 40 | 25% |
