## 1. 渲染层级

Canvas 2D 分层渲染，按顺序绘制：

| 层级 | 内容 | 说明 |
| --- | --- | --- |
| 1. 背景 | 地面/地形贴图 | 静态，可离屏缓存 |
| 2. 地形障碍 | 墙壁/障碍物 | AABB |
| 3. 掉落物 | 金币/碎片/装备光点 | 闪烁动画 |
| 4. 敌人 | 敌人本体+血条 | 按y排序伪深度 |
| 5. 刀体特效 | 玩家+敌方刀体、刀光拖尾 | 核心视觉 |
| 6. 粒子 | 命中火花/拼刀火花/击杀特效 | 短生命周期 |
| 7. UI | HUD/升级面板/对话 | 最上层 |

## 2. 刀体旋转渲染（BladeRenderer.ts）

利用 Canvas 变换矩阵实现旋转：

```typescript
class BladeRenderer {
    draw(ctx: CanvasRenderingContext2D, blade: BladeEntity): void {
        ctx.save();
        ctx.translate(blade.center.x, blade.center.y);
        ctx.rotate(blade.angle);               // 旋转到当前角度

        // 刀光拖尾（残影）
        this.drawTrail(ctx, blade);

        // 刀柄
        ctx.lineWidth = blade.width * 1.2;
        ctx.strokeStyle = '#8B7355';
        ctx.beginPath();
        ctx.moveTo(0, 0);
        ctx.lineTo(blade.length * 0.35, 0);
        ctx.stroke();

        // 刀刃
        const grad = ctx.createLinearGradient(blade.length * 0.35, 0, blade.length, 0);
        grad.addColorStop(0, qualityColor(blade.quality));
        grad.addColorStop(1, 'rgba(255,255,255,0.9)');
        ctx.lineWidth = blade.width;
        ctx.strokeStyle = grad;
        ctx.beginPath();
        ctx.moveTo(blade.length * 0.35, 0);
        ctx.lineTo(blade.length, 0);
        ctx.stroke();

        ctx.restore();
    }

    private drawTrail(ctx: CanvasRenderingContext2D, blade: BladeEntity): void {
        // 记录最近 N 帧的角度，绘制渐变弧光
        for (let i = 0; i < blade.trail.length; i++) {
            const t = blade.trail[i];
            const alpha = (i / blade.trail.length) * 0.4;
            ctx.strokeStyle = `rgba(255,255,255,${alpha})`;
            // 绘制历史角度的弧线...
        }
    }
}
```

```typescript
    return { white:'#ddd', green:'#6f6', blue:'#6cf', purple:'#c6f', orange:'#fc6' }[q];
}
```

## 3. 粒子系统（ParticleSystem.ts）

```typescript
interface Particle {
    pos: Vec2; vel: Vec2; life: number; maxLife: number;
    size: number; color: string; type: 'spark'|'glow'|'shard';
}

class ParticleSystem {
    private pool: Particle[] = [];
    emit(pos: Vec2, count: number, opts: ParticleOpts): void { /* ... */ }
    update(dt: number): void {
        for (const p of this.pool) {
            p.pos.x += p.vel.x * dt;
            p.pos.y += p.vel.y * dt;
            p.life -= dt;
            p.vel.x *= 0.92;   // 阻尼
            p.vel.y *= 0.92;
        }
        this.pool = this.pool.filter(p => p.life > 0);
    }
    draw(ctx: CanvasRenderingContext2D): void { /* ... */ }
}
```

| 事件 | 粒子 |
| --- | --- |
| 命中 | 5-8 火花，朝命中切线方向 |
| 击杀 | 12 碎片+光点扩散 |
| 拼刀 | 16 火花四溅+白光闪 |
| 破刀 | 24 刀刃碎片+慢镜头 |
| 升级 | 金色光环上升 |

## 5. 屏幕震动与后处理

```typescript
class Camera {
    shake(intensity: number, duration: number): void { /* ... */ }
    apply(ctx: CanvasRenderingContext2D): void {
        if (this.shakeTime > 0) {
            const dx = (Math.random() - 0.5) * this.shakeIntensity;
            const dy = (Math.random() - 0.5) * this.shakeIntensity;
            ctx.translate(dx, dy);
        }
    }
}
```

## 6. 渲染性能优化

| 策略 | 说明 |
| --- | --- |
| 离屏 Canvas | 背景层缓存到离屏 Canvas，每帧直接 drawImage |
| 视口裁剪 | 仅渲染屏幕可见区域的实体 |
| 批量绘制 | 同类粒子合并绘制路径 |
| 脏矩形 | UI 静态部分仅在变化时重绘 |
| 限制粒子数 | 同屏粒子上限 500，超出丢弃最老 |
