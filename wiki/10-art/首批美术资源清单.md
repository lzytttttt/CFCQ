# 首批美术资源清单：铁匠铺战斗核心包

## 项目盘点

《藏锋出鞘》是 HTML Canvas 2D + TypeScript 的俯视角 Rogue 转刀动作游戏，世界尺寸为 2400×1350，逻辑视口为 1920×1080。原战斗渲染主要由 Canvas 原语构成：地面为纯色与网格，玩家为朱红方块，普通敌人与 Boss 为色块圆形，刀具和拖尾由 `BladeRenderer` 程序绘制。`RenderSystem` 已有背景、敌人、刀具、粒子和 HUD 分层，可在不改变碰撞逻辑的前提下挂载静态 PNG。

本仓库原先没有 `wiki/assets/concept-art/` 或游戏运行时美术 PNG；旧总表第 9 节所列的“已生成”索引与当前仓库不符，应视为历史清单而非已交付文件。数量也有差异：需求文档称 20 把刀，刀具图鉴实际以 19 把为准。后续扩量前需要统一索引。

## 接入验收

- 图片加载失败或尚未完成时，原有 Canvas 绘制继续可用，不会阻塞战斗。
- 贴图只改变视觉，不改变碰撞半径、刀长、伤害或升级数值。
- 角色与敌人保持中心锚点；铁匠刀刀根在左，刀尖朝右。
- 玩家无敌闪烁、敌人受击反馈、Boss 刀具与 HUD 仍保留。
- `npm test`、`npm run build` 均通过。

## 代码改动路径

- `src/render/ArtAssets.ts`：图片懒加载与缓存，未加载/不在浏览器/加载失败时返回空值并由调用方回退。
- `src/states/BattleState.ts`：关1背景、玩家和山匪喽啰精灵挂载。
- `src/render/BladeRenderer.ts`：可选横向刀贴图绘制；未提供图片时沿用原有程序刀体。
- `public/assets/art/`：本轮四张 PNG 运行时美术资源。
