# 美术资源需求汇总

> 本文档汇总《藏锋出鞘》开发所需的全部美术资源，作为美术/程序协作的交付清单。
> 资源按 **角色 / 刀具 / 敌人 / Boss / 场景 / UI特效 / 音频视觉联动** 分类，每项标注格式、尺寸、风格与优先级。
> 概念美术图参见 `assets/concept-art/`（6 张已生成，整体风格为 **卡通 2D 武侠**）。

---

## 0. 全局美术规范

| 项目 | 规范 |
| --- | --- |
| 整体风格 | **卡通 2D 武侠**：扁平卡通画风，干净流畅的黑色描边线条，明快大块色填充，简洁色块无复杂阴影，类似现代国风动画的清爽卡通质感；刀光用高饱和冷色/暖色点缀 |
| 色彩基调 | 铁匠阶段：暖橙炉火/赭石褐；武林阶段：玄黑/鎏金 + 朱红旗帜，整体明快鲜亮，避免暗沉 |
| 分辨率基准 | 角色 512×768、道具 512×512、场景 1920×1080 |
| 帧率 | 动画 12–24 fps（刀光/打击感优先于流畅度） |
| 文件格式 | 位图 `.png`（透明通道）；序列帧用 `.png` 雪碧图 + `.json` 帧数据 |
| 坐标系 | 角色中心锚点（与转刀圆心一致），刀体以锚点旋转 |
| 命名规范 | `类型_名称_状态_帧序号`（如 `char_chenfeng_idle_01.png`） |

> 风格说明：v0.3 起美术方向由"国风水墨+厚涂暗色调"调整为"卡通 2D 武侠"，全部资源（含已生成概念图）重绘为扁平卡通描边风格，配色明快，强调辨识度与可读性，适配移动/PC 双端轻量渲染。
